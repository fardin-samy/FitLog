# FitLog

FitLog is a focused workout library and daily planning app. Browse exercises, inspect detailed instructions, build a plan for today, and keep saved workouts ready for later.

## Technologies

- Next.js 16 with the App Router
- React 19
- Tailwind CSS 4
- JavaScript
- Browser `localStorage` for plan and saved-workout persistence
- FitLog workout API for exercise data

## Key Features

1. **Workout library**: Browse exercise cards with images, muscle groups, equipment, duration, calories, and ratings.
2. **Sorting**: Reorder the library by Duration, Calories, or Rating with the Sort By dropdown.
3. **Workout details**: View exercise instructions and metadata, then add a workout to today's plan or save it for later.
4. **My Plan tracking**: Review plan and saved workouts, see live exercise/minute/calorie totals, mark workouts as done, or remove them.
5. **Responsive experience**: Use the library, detail pages, navigation, loading state, custom 404 page, and toast feedback comfortably across mobile, tablet, and desktop screens.
